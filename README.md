# GymGen AI - AI Powered Fitness Coach

GymGen AI is a comprehensive, cross-platform fitness application built with Flutter. It generates personalized workout plans, tracks nutrition, visualizes progress, and features an AI-powered fitness coach. The app features a premium dark-mode UI with a custom animated galaxy background.

## ✨ Features

*   **Authentication:** Secure Email/Password and Google Sign-In via Firebase.
*   **AI Coach:** Fast, conversational AI fitness advice using the Groq API (Llama 3) with Markdown rendering.
*   **Smart Workouts:** Generates personalized plans based on user assessments.
*   **Workout Player:** Interactive workout execution with rest timers and exercise video guides.
*   **Nutrition Tracking:** Daily calorie, macro, and water logging.
*   **Progress Analytics:** Visual charts for weight progress and weekly workout activity.
*   **Cloud Sync:** Offline-first architecture syncing with MongoDB Atlas via a custom Node.js REST API.
*   **UI/UX:** Premium dark-mode design featuring a custom animated Galaxy Background.

## 🛠️ Tech Stack

*   **Frontend:** Flutter, Dart, Provider (State Management), fl_chart
*   **Backend/Database:** MongoDB Atlas, Node.js (Express), Render (Hosting)
*   **Authentication:** Firebase Auth
*   **AI Integration:** Groq API (OpenAI-compatible)
*   **Local Storage:** SharedPreferences
